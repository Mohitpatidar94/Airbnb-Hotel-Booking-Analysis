# Dataset

## Airbnb Hotel Booking Analysis

This project uses an Airbnb listing dataset containing information about properties, hosts, prices, reviews, locations, and availability.

### Dataset Details

- **Rows:** 102,599
- **Columns:** 26
- **Original format:** Excel (.xlsx)

### Main Data Categories

- Property and room types
- Host details and verification
- Neighbourhood and location
- Price and service fee
- Minimum nights
- Number of reviews
- Review rate
- Construction year
- Host listing count
- Availability
- Cancellation policy

### Dataset Source

[Download Airbnb Hotel Booking Analysis Dataset](https://voisfortech.com/storage/files/1776250134-P4-Airbnb%20Hotel%20Booking%20Analysis.xlsx)

### Note

The original Excel file is not included in this GitHub repository because of its large file size.

The dataset was cleaned and analysed using Python. The complete analysis is available in `Airbnb_Hotel_Booking_Analysis.ipynb`.
